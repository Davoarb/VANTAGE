## 🏛️ Hybrid Architecture V2

After facing Overwolf's restrictive UI policies, we pivoted to a 100% proprietary and undetectable engine. The tool is separated into two main blocks for security and performance:

### 1. The Local Collector (Vantage Manager)

- **Nature:** An ultra-lightweight, native desktop application built with **Tauri (React on the Frontend, Rust on the Backend)**.
- **Hybrid Performance:** The interface minimizes to the system tray during matches. The Rust backend uses a `Mutex` to ensure only one Node.js process is running, and it features an auto-shutdown (`process.exit(0)`) upon match upload to guarantee **0% CPU and RAM consumption** post-match.
- **Method (Anti-Vanguard):** **0% memory reading**. It passively reads the `ShooterGame.log` file generated by Unreal Engine to catch the exact `MatchID` the moment the scrim ends.
- **Data Extraction:** It utilizes the game's local port (`LCU`), extracting the port and password from the `lockfile`. This allows us to use internal authorization *Tokens* (`Entitlements` and `Bearer`) to make a direct request to Riot's web servers (`pd.eu.a.pvp.net`), bypassing 403 and 404 errors. By adding the `X-Riot-ClientPlatform` and `X-Riot-ClientVersion` headers, we bypass the 400 error.
- **Output:** A `.json` file identical to official VCT telemetry, automatically sent via `POST` to our SaaS.

### 2. The Brain (Next.js API Route)

- **Nature:** Private endpoint on Vercel (`/api/upload-pracc`).
- **Security:** Keeps Supabase credentials (`DIRECT_URL`) completely secure on the server. The desktop app never knows the database exists.
- **Modular Architecture:** To prevent "Spaghetti Code", the API route is strictly separated into three layers:
  1. `constants.js`: Dictionaries for agents, maps, and weapons.
  2. `analytics.js`: The mathematical engine that calculates KAST, dissects the economy, maps the radar, and detects Clutches/Multi-Kills.
  3. `route.js`: Exclusive for the database connection.
- **Fault Tolerance:** Implements safe error catching for Prisma's unique constraint errors (`P2002`) to elegantly ignore any attempt to upload a duplicate scrim.
- **Injection:** Uses `Prisma Client` to save the processed data (hybrid Relational/Document storage via a JSONB field for the `rawTimeline`) into Supabase. Immediately after, the coach can view the scrim on their web dashboard.
